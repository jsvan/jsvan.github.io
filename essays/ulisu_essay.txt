I was on an airplane with my books in Czech when I had this idea. I need to understand the books I've purchased, and I should practice each page's vocabulary words as flashcards before attempting to read each page. www.ulisu.com does just that. It is an offline solution that has profile management for texts and vocabulary. You can upload epubs, pdfs, photos, or txt documents, and it will find the core vocabulary on the page. Each word is sent to its root form with in memory dictionaries. Memory is so cheap now this is not an issue, but originally I was using an API that would return root word forms. That of course overkill and prevented an offline solution. The flashcards are then translated to English with another in memory dictionary, and the words filtered by your profile to exclude already seen words. So far this works great. I would love to turn it into an app, but so far it functions as a webapp that I've installed to my iphone's home page.
